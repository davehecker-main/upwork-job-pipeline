# Style examples

Drop 2-3 of your best past proposals here as `.md` files. They are inlined into
the drafting prompt as style anchors, which is the single highest-leverage
input to draft quality — the model imitates what it is shown far more reliably
than it follows instructions about tone.

Pick proposals that got a reply, not the ones you liked writing. Strip client
names if you would rather not have them in a public repo.

Until you add real ones, `example-placeholder.md` keeps the prompt structurally
valid but contributes nothing useful.
